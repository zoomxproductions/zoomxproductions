## Languages

English, French, and Spanish are supported on all pages. Site text lives in `assets/i18n-en.js`, `assets/i18n-fr.js`, and `assets/i18n-es.js`. Language selection persists across pages where browser storage is available.

## Design

Editorial, work-forward visual system based on the supplied Zoom-X identity. Off-white background, near-black type, precise spacing and sparing metallic-gold accents. No artificial portfolios, invented testimonials, unlicensed client work or simulated statistics.

## Contact and pricing

There is no public price list. Inquiries are directed to **info@zoomxproductions.com**.

The contact form currently opens the visitor's email application with a populated quote request (`mailto:`); it does not silently store or transmit submissions. A server-side form service and abuse protection should be added if a browser-only form is required.

## Deploy

This is a dependency-free static site. Deploy all `.html` files and the `assets` folder together to any static host (GitHub Pages, Cloudflare Pages, Netlify, etc.).

**DNS/domain connection is not configured by this repository.** Configure the target domain in your chosen hosting provider, then adjust `sitemap.xml` and any canonical settings to the final URL.

## Real media still needed

To achieve a truly bespoke production-company presentation, replace the typographic media placeholders with **actual Zoom-X work**:
- Three strong approved project stills or video showreel footage
- Videography/photo project titles and client-authorized credits

The layout intentionally does not misrepresent stock footage as original client work.
