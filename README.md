# Zoom-X Productions — compact studio website (v4)

Ten-page responsive site in English, French, and Spanish.

## Pages
- index.html — services-led homepage, real journalism profile and small work directory
- work.html — compact portfolio references with working category filters
- services.html — service overview
- service-video-photo.html — video and photography
- service-journalism.html — journalism and media
- service-digital.html — websites and mobile apps
- service-marketing.html — marketing and digital content
- about.html — studio overview
- contact.html — inquiry form (opens visitor's email application)
- work-koneksyon.html — small Koneksyon reference with iOS and Android links

## Site assets
Shared CSS and JS are in `assets/`. `assets/site-v4.css`, `assets/site-v4.js` and `assets/i18n-v4.js` refine the original reusable source without removing it. `wisly-portrait.jpg` is a crop from the user-supplied Facebook screenshot.

## Notes
No public pricing is published. Quotes go to info@zoomxproductions.com. Portfolio links are references, not unverified claims of studio authorship. Obtain rights/confirm individual credits before presenting any item as Zoom-X client work. No stock/AI portfolio imagery or invented statistics are included.

The contact form is a `mailto:` launcher, not a server submission. For reliable on-site submissions, connect a proper form backend and spam protection.

## Deploy
Deploy the root `.html` files plus the full `assets/` directory to any static host. Update your host's domain/DNS settings separately. The website is not yet published to the custom domain by this repository change.
